# 🛣️ RideFlow — Transport Management System

A complete, production-ready full-stack transport booking platform for Sri Lanka built with PHP, MySQL, HTML, CSS, and JavaScript.

## ✨ Highlights

- **3 user roles**: Admin, Customer, Driver
- **Auth**: Email/password, Phone/OTP, Google OAuth 2.0, email verification, password reset
- **Booking engine**: Live seat availability, multi-seat booking, QR e-tickets
- **Payments**: Stripe, PayPal, Dialog eZ Cash, Genie, Bank Transfer, Cash — all simulated/ready for real API keys
- **AI Chatbot**: Claude-powered assistant with FAQ fallback, floating widget on every page
- **Admin Panel**: Dashboard analytics, bookings, users, vehicles, routes, schedules, drivers, payments, reports, chatbot FAQ, newsletter, settings
- **REST API**: Full mobile API under `/api/v1/` with Bearer token auth
- **Extras**: Newsletter, contact form, feedback/reviews, real-time notifications, dark responsive UI

See **`SETUP_GUIDE.md`** for full installation instructions, API integration guides, and troubleshooting.

## Quick Start

```
1. Copy this folder to htdocs/www
2. Import sql/rideflow.sql
3. Edit config/config.php
4. Visit /rideflow/ — login as admin@rideflow.lk / password
```
